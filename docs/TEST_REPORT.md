# ResearchAgent - Test Report

## Summary

| Kind of testing | How to run | Result |
|---|---|---|
| Automated tests (offline, about 1 s) | `python -m pytest -q` | **30 / 30 passed** |
| Fresh install | new virtual environment + `pip install -r requirements.txt` + tests | installs cleanly, 30 / 30 passed |
| Evaluation benchmark (real LLM) | `python tests/evaluate.py` | see [evaluation_results.md](evaluation_results.md) |
| Live checks in the app (real LLM, browser) | `./run.sh`, sample papers | see "Live checks" below |
| Dependency vulnerability scan | `pip-audit -r requirements.txt` | no known vulnerabilities |

**How the automated tests work.** The language model and the embedding model are replaced by simple fakes (`FakeLLM` gives a fixed JSON reply for each kind of prompt; `FakeEmbedder` turns words into vectors). Everything else is the real code: PDF reading (on small PDFs generated by the test file), chunking, search, planning, all tools, guardrails and the SQLite accounts. The fakes can also return bad or failing replies to test error handling.

## Defects found and fixed

| # | Defect | Found by | Fix |
|---|---|---|---|
| 1 | Original code could not call the LLM on a fresh install (`groq==0.11.0` vs current `httpx`) | first install | updated the Groq SDK |
| 2 | Every table and chart crashed (NumPy / `pyarrow` version clash) | first app run | updated the pins |
| 3 | 50+ known vulnerabilities in the pinned packages (incl. the PDF parser) | `pip-audit` | updated all pins |
| 4 | Two-column PDFs gave merged words and mixed-up columns; a centred title was cut in half | real papers | column-aware reading with the title block read first |
| 5 | "system prompt" in a real paper was flagged as an attack | real papers | narrowed the pattern + test TC09 |
| 6 | A reworded jailbreak passed the pattern check | manual attack | Llama Prompt Guard 2 + test TC20 |
| 7 | Guardrails could be bypassed with invisible / full-width characters | security test | text normalisation + test TC08 |
| 8 | Paper and API text could be shown as raw HTML (XSS) | code review | escape everything; only `http(s)` links |
| 9 | The reasoning model ran out of tokens before finishing its JSON | live run | low reasoning effort + larger token budget |
| 10 | The fallback model had been retired; free-tier rate limits slowed runs | live run | second current model, switch on HTTP 429 |
| 11 | One request hung for 26 minutes | evaluation | 45 s timeout, no hidden SDK retries |
| 12 | Honest but incomplete answers when the first search missed a passage | evaluation | search deeper when the draft is incomplete + test TC18 |
| 13 | Research gaps were not always checked against literature | live run | added as a fixed policy + test TC19 |
| 14 | Sign-in fields invisible; sidebar button text cut off | browser screenshots | style fixes |
